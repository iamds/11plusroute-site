About CEM

CEM's entrance test is now called Cambridge Select Insight. Cambridge says it is suitable for 11+, 13+ and late transfer to grammar schools.

It has verbal, numerical and non-verbal sections and takes about 60 minutes on average.

Schools that use it

The Blue Coat School, Liverpool
A two-phase online test. Phase 1, in July of Year 5, uses Cambridge Primary Insight: reading, spelling, maths, mental arithmetic and a 'developed ability' section. Phase 2, in September, tests verbal, numerical and non-verbal ability. Extra time is considered only in Phase 2.
Mayfield Grammar School, Gravesend
The optional Mayfield test is a CEM computer test of verbal, maths and non-verbal skills (weighted 50%, 25% and 25%), plus a written English paper set by the school.

What the test is like

  • The test is on a computer. Each section has its own time limit.
  • Question formats include multiple choice, drag and drop, and completing words.
  • Cambridge offers versions with 25% extra time.

Free practice materials

  • CEM Select familiarisation
    A free online practice run of the on-screen format.

Cambridge says there are no past papers and no practice papers.

Marking and scores

Scores are age-standardised. Schools can also see raw scores for ranking.

Access arrangements

  • Ask the school about access arrangements. At Blue Coat, the Phase 1 test has no extra time or modified versions.

Each school's page says which test it uses and who sets each part. Always check the school's own admissions policy.
